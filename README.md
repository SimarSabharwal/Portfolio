# Portfolio

Personal portfolio website for **Simar Sabharwal** — Full-Stack Developer, UI Architect, and Creative Designer.

## 🚀 Built With
- **React 18** & **TypeScript**
- **Vite**
- **Tailwind CSS**
- **Lucide Icons**

## 🛠️ Getting Started

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
